# reids模块
**已实现功能**
- [x] 建立发布连接和订阅连接
- [x] 订阅频道
- [x] 取消订阅频道
- [x] 发布消息，消息内容（包括空格）能到达订阅端
- [x] 能收到消息并调用回调（Redis 订阅线程收到消息后再交给业务层转发）
- [x] 配置管理：Redis 地址、端口和可选密码从 `config.json` 读取

**未实现功能**
- [ ] 线程安全：Subscribe、Unsubscribe 和观察线程会访问同一个订阅连接，需要进一步确认并发读写是否安全。
- [ ] 连接恢复：Redis 断开后，观察线程会退出；目前没有重连机制。
- [ ] 订阅确认：当前 Subscribe 发送命令后就返回，没有确认 Redis 已完成订阅。
