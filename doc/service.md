# 业务模块
**已实现功能**
- [x] 注册
  - [x] 接收手机号、昵称、密码，生成用户 ID 后写入 MySQL
- [x] 登录
  - [x] 支持按昵称查询账号，校验密码和在线状态；
  - [x] 支持按手机号查询账号，校验密码和在线状态；
  - [x] 成功后记录用户连接、订阅 Redis 个人频道、更新在线状态，并查询和返回离线消息。
- [x] 好友查询：可按昵称或手机号查询用户信息，返回用户 ID、昵称和手机号。
- [x] 好友申请与处理
  - [x] 转发好友申请
  - [x] 接收接受/拒绝结果。
    - [ ] 接受时会在 MySQL 中写入双方的好友关系。在线用户通过连接或 Redis 收消息，离线用户的消息会暂存到离线消息表。
- [x] 一对一聊天
  - [x] 根据接收方 ID 将消息发送给在线用户
  - [x] 用户在其他服务实例上在线时通过 Redis 发布
  - [x] 用户离线时保存消息，待其登录后取回
- [x] 连接断开处理
  - [x] 移除用户连接
  - [x] 取消 Redis 订阅
  - [x] 将用户状态更新为离线
